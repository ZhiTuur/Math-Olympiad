### TECHNICAL:

**Documents:**
Find my math documents in here.

**Auxilary files deleter:** 
MiKTeX compiler creates temporary files; this is the folder is a script that automatically deleted them for decluttering. The file 'latexmkrc' is part of it but cannot be placed in folders due to script run order.

**General:** 
General documents in connection with MO without containing actual math is stored here; eg. my manifesto

**Style file:**
My own modular LaTeX style package, TLZLaTexPack.sty is stored here.

**.gitignore:**
Since I chose to delete temporary files; I let Git ignore them for some extra efficiency when compiling.
